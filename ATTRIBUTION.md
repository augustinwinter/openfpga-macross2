# Third-party provenance and attribution register (DRAFT)

**Status: documentation audit, NOT final license clearance.** This register records evidence from the clean Quartus source tree and published upstream projects (CP48AS, 2026-10-16). **The repository is private and no 77-file RTL distribution has been approved.** Retaining a license file is necessary but not by itself sufficient for distributing a modified FPGA core or its compiled binary.

The hardware-verified core implements **Super Spacefortress Macross II**, with no copyrighted arcade ROM dumps in this repository. Game data and artwork licensing are separate from software/HDL attribution; see [REPRODUCING.md](REPRODUCING.md).

## Active-source inventory and outstanding questions

CP48AO found **77 active HDL files** (73 directly declared in `projects/m2_pocket.qsf` plus 4 from generated-IP QIPs). The wider source tree contains 232 HDL files, many not part of the active build. A coarse header scan flagged **26** active HDL files for provenance review; this number is *not* a count of infringement or unlicensed files.

CP48AP found no literal Verilog `\`include` entries and **20** `$readmemh/$readmemb` references. CP48AQ-2 and CP48AR proved that the two FX68K microcode files are **required by Quartus**, found through the QSF `SEARCH_PATH`, and have canonical checksum matches. Other parameter-conditional ROM-memory loads must be distinguished between simulation configurations and actual synthesis inputs. Some QIP entries point to missing optional auxiliary `MISC_FILE` entries (`.ppf`, `.cmp`); preserved Quartus success does not make those licensing questions vanish.

## Release gate — do not publish binaries or RTL before completing

1. Record **upstream repository URL and immutable commit/tag** for each third-party and derived active component, and source hashes of any imported files.
2. Determine whether local edits modified copyrightable upstream expression, and preserve authors' original notices and complete license texts in source and release documentation.
3. Verify permission to distribute vendor-generated IP and any embedded/generated memory images.
4. Verify the generated T80 input and full Yosys 0.52 command so others can regenerate the exact Verilog; carry forward the T80 notices and conditions.
5. Collect complete corresponding source for applicable copyleft components; determine overall license compatibility and GPL obligations before releasing a compiled FPGA binary.
6. Complete a fresh checkout Quartus 25.1std.0 Lite Edition build on a supported x86_64 host, compare timing/resource reports, regenerate the `.rbf_r` with [tools/convert-rbf.py](tools/convert-rbf.py), and perform any needed hardware regression.
7. Release only an authorized ROM-free package with rights-cleared artwork, accompanied by [REPRODUCING.md](REPRODUCING.md) instructions for locally constructing original-game assets.

**No declaration of source ownership, relicense, or legal redistribution authorization is made by this draft.** See [BUILDING.md](BUILDING.md) for toolchain settings and reproducibility limits.
